## Precise corrections identified

1. **Recovery figure:** `scripts/plot_results.py::recovery` draws signal-recall bars and pairwise support-stability diamonds. The template caption instead describes lower FDP/NDP. The final caption should describe recall (higher is better) and descriptive stability; FDP/NDP can remain in the tables. Alternatively change the figure to match its caption.
2. **Solved-fraction figure:** `optimization_success` contains solved fraction only. The template caption calls it solved fraction and search effort. Remove the search-effort description or add the corresponding panel; the result tables already contain support/call counts.
3. **Archived whole-run failures:** the internal identical-master retry correctly shares the existing remaining wall budget. A separate replay of an entire failed run must distinguish that policy from a fresh run. If a replay receives a fresh 30 seconds and also charges the original elapsed time, its total computational allowance can exceed the primary 30-second cap. Use the remaining allowance or report it explicitly as extra-budget remediation, preserving the original capped comparison. This was a policy clarification while the replay script was being prepared, not a claim that an inspected replay had already violated the cap.

## Checks completed

**Data independence and preprocessing.** Synthetic selection, downstream training, and final classification use separate random streams; fresh equality-test batches use separate seed families. Real-data indices are partitioned within each class into disjoint selection, head, and test groups. A read-only scan found no split overlap in the available saved records. The pooled center and sample SD are fitted solely on selection observations, then reused for every support, head, and test. Semantic feature mapping restores shuffled synthetic positions before stability/recovery assessment.

**Equality testing.** The common RBF bandwidth is fitted on selection observations, not final labels. The final Gram matrix is held fixed under label assignments. The code's within-group diagonal exclusions and cross-group quadratic-form arithmetic implement the unbiased two-sample statistic. The plus-one p-value uses 199 fixed-size random assignments and the declared 0.05 rejection threshold. Conditional batches are aggregated within seed before bootstrap resampling; real-data variability is split SD. Prediction error and equality-test null rejection remain different saved metrics.

**Wang baseline.** The independently written coefficient matrix is negative regularized row covariance, matching the paper's mean-minus-variance criterion. The inspected revision's positive coefficient sign is separately reconstructed for comparison. Documentation labels this a paper-objective reproduction and discloses the official-source discrepancy, fixed hyperparameter and final-bandwidth adaptation. Small support problems use a global sphere-quadratic fit including the hard case; large-dimensional support search is labeled approximate. Native learned weights remain signed. Permutation calibration remains interpretable for the frozen signed statistic, but it is not asserted to be a positive-definite-kernel MMD. The common support-only RBF test is separate.

**Solver statuses and timing.** The current outer solver uses `mip_dual_bound` only from master statuses 0/1, with the optimal objective as a fallback only at status 0. Error results contribute neither incumbent nor lower bound. The status-4 retry reuses the identical model with presolve disabled, at most once, and charges both calls to the master and total elapsed time. A repeated support with unresolved gap receives an accuracy status. Fractional evaluations do not update the deployable upper bound. Ratio rows retain affine cuts, use one shared product vector, and rebuild the cap from a feasible original upper bound.
