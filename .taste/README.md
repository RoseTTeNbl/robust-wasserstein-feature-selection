# 写作与代码口味（.taste）

这里记录本项目作者对论文、数学和代码的长期要求。它们不依赖具体项目，可以整个目录复制到别的仓库。
任何 agent 在动笔、改证明或改代码之前先读对应文件；项目自己的 `AGENTS.md` 与这里冲突时，以 `AGENTS.md` 为准。

| 文件 | 什么时候读 |
| --- | --- |
| [writing.md](writing.md) | 写或改论文、理论笔记、研究方向笔记、文档 |
| [math.md](math.md) | 写公式、定义、命题和证明 |
| [code.md](code.md) | 写或改算法代码、测试、实验脚本 |

三条总原则：

1. **读者用最少的力气看懂。** 一条主线，按顺序推进；每个符号、每句话都要有用。
2. **改动要小而准。** 只改需要改的地方，保留作者已有的记号和结构；不要借机整体重写。
3. **诚实。** 数字来自真实运行；开发检查与正式结论分开；失败、超时和“没用”的结果照样写。
