\begin{abstract}
We evaluate robust feature selection using a separate validation of subset search and a frozen study of statistical utility. On 16 predeclared confirmation configurations, storing the dual fractions already obtained by full evaluation reduces complete subset solves by 24.2\%, while summed median runtime changes by +4.3\%. The reference study compares four synthetic alternatives and two public datasets using independent selection, classifier fitting and testing. Global empirical-risk optimality does not yield uniformly better testing power or prediction. All comparisons, time limits and failures are retained; results from earlier search versions remain labeled separately.
\end{abstract}

\section{Experimental design and implementation}\label{sec:design}
The report separates two bodies of evidence. The frozen reference study evaluates
an earlier global-cut implementation with five fractional root rounds. Its statistical
outcomes describe those recorded supports, not the current search implementation.
The new validation study compares ways of choosing the next binary subset; its
rule is selected on development cases and then assessed on separate confirmation
cases. The robust objective is shared, but the search versions and timing cohorts
are not pooled.

The experiment design follows the distinction between computation, two-sample
power and support recovery in Wang et al.~\cite{wang}. Independent prediction
and small-sample error evaluation follow robust-testing studies~\cite{xie,sinkhorn,neural}.
These references motivate the measurements; the experiments below are adaptations
for a common feature budget rather than replays of published tables.

\subsection{Data, splits and fixed settings}
Synthetic class zero has independent standard-normal coordinates. Class one
changes a hidden signal block: a mean shift of $0.9$, standard deviation $1.8$,
equicorrelation $0.65$ with unchanged marginals, or a shared random sign times
$1.5$ added to its coordinates. Remaining coordinates are standard-normal noise.
Positions are shuffled, while recovery uses stable underlying feature identities.
The dependence alternative requires joint measurements; the mixture has equal
means but different shape and dependence.

\subsection{Compared selectors}
All six practical selectors use the same acquisition budget. Global risk minimizes
the sum of classwise worst-case half-hinge losses over class-conditional empirical
Wasserstein balls, with standardized $L^1$ transport. Each selected subset is fully
refitted. The finite formulation, dual cuts and whole-space test are described in
the accompanying theory note; this report concerns their implementation and evidence.
Maximum mean discrepancy (MMD) compares within-class kernel similarities with
cross-class similarities to measure a distribution difference. The Gaussian
radial-basis-function (RBF) kernel is
$k(x,y)=\exp[-\|x-y\|_2^2/(2b^2)]$, where $b^2$ is a fixed squared bandwidth.

The Wang implementation reproduces the paper's mathematical criterion, not a
literal author-script run. The inspected revision rewards a positive variance
term, and its testing routine refits bandwidths using test labels. Our variance
term is negative and all testing bandwidths are frozen from selection data.
Its native signed additive statistic is reported separately from the common
joint RBF test. Known-signal and all-feature supports are diagnostics; the former
is unavailable in practice and the latter uses a larger budget.

Every selected support receives the same robust classifier and RBF SVM, both fitted
on the independent downstream sample. The robust classifier uses the same radius
and half-hinge objective; the SVM uses $C=1$ and a downstream-only median bandwidth.
This holds the evaluation model fixed while comparing selected coordinates.

\subsection{Measurements and uncertainty}
Two-sample power is the rejection fraction on independent alternative batches;
null rejection uses separate batches drawn from the same class-zero distribution.
The common statistic $T$ is an unbiased estimate of squared joint RBF MMD. Its pooled-selection median
squared-distance bandwidth is frozen, and 199 fixed-size label permutations give
\begin{equation}\label{eq:permutation}
p=\frac{1+\#\{T_{\rm perm}\ge T_{\rm observed}-10^{-14}\}}{200},\qquad
\text{reject if }p\le0.05.
\end{equation}
Methods share the same batches and permutation seeds. This null rejection rate
is distinct from a classifier's class-zero error.

For selected set $S$ and true signal set $T_*$, recovery is measured by
\begin{equation}\label{eq:recovery}
\operatorname{recall}=\frac{|S\cap T_*|}{|T_*|},\qquad
\operatorname{FDP}=\frac{|S\setminus T_*|}{\max\{1,|S|\}},\qquad
\operatorname{NDP}=1-\operatorname{recall}.
\end{equation}
For the six budget-matched synthetic selectors, $|S|=|T_*|=3$,
so precision and F1 equal recall and FDP equals NDP. This equivalence does
not apply to the all-feature diagnostic. We show recall rather than repeat equivalent outcomes. Pairwise
Jaccard support stability is descriptive and remains in the complete data.
No true support is claimed for real datasets.

Let $p_0(x)$ be the robust classifier's probability of class zero. Hard decisions
use threshold $0.5$, with ties assigned to class zero. Its randomized error and
the common hard-classification measure are
\begin{equation}\label{eq:errors}
\begin{aligned}
\operatorname{BER}_{\rm hard}&=\tfrac12(\operatorname{FPR}+\operatorname{FNR}),\\
\operatorname{BER}_{\rm random}&=\tfrac12\{\mathbb E_0[1-p_0(X)]+\mathbb E_1[p_0(Y)]\}.
\end{aligned}
\end{equation}
FPR is the class-zero probability of predicting class one; FNR is the
class-one probability of predicting class zero. The SVM uses decision threshold
zero, again assigning ties to class zero.
The second equals the half-hinge average; these are not separate endpoints.
AUC uses class-one scores. Balanced predictive cross-entropy averages the two
classwise negative log probabilities, clipped at $10^{-12}$; it evaluates
probability quality and is not the optimized half-hinge objective. These secondary
outcomes and classwise errors remain in the linked per-trial data.

Optimization outcomes are actual lower and upper bounds, their gap, solved
fraction, distinct fully evaluated subsets and charged time. Reference runs use
one 30-second selection allowance and declare numerical optimality at gap
$10^{-6}+10^{-5}|\mathrm{UB}|$. Failed attempts and same-model retries are charged
and remain in denominators. Synthetic intervals are 95\% percentile bootstrap
intervals from 2,000 resamples of training seeds; testing batches are first
averaged within seed. Real results are mean $\pm$ split SD, since splits overlap.

\section{Validation of the revised subset search}\label{sec:search}
The computational question is whether choosing and screening subsets more carefully reduces expensive full evaluations. Each selected binary subset is fully solved, gives an actual feasible test and contributes one tangent. No old test is transferred to a new subset.

The original search predicts mean risk and model standard deviation from completed evaluations, then ranks up to eight eligible proposals by mean minus standard deviation. The revision retains the same predictor, proposals and refresh interval. It also stores the safe dual fraction already returned by each full evaluation. A candidate is screened using the largest stored tangent or fraction value. The periodic master also retains these fractions. This uses existing certificates and adds no continuous oracle stage.

The implementation repeats four steps: (1) exclude proposals whose stored lower bound exceeds the incumbent minus half the target tolerance; (2) rank the remaining proposals; (3) fully solve the chosen subset and store its test, tangent and fraction; (4) refresh the global master after three completed evaluations or when no proposal survives. The actual test updates the upper bound; the master supplies the global lower bound and stopping test.

Here $T$ is the recorded support-evaluation count (the solver's visited counter). It is separate from the count meeting inner precision: a limited run may record a final evaluation that misses this target. Every recorded anchor in the current validation meets $\varepsilon/4$. Physical oracle attempts may include refinements; continuous solves count the primal and dual solver calls inside them. Master calls and master time measure the separate integer-search cost. Numerical accuracy is checked against exhaustive support enumeration, not only the reported outer gap.

\subsection{Development and the fixed rule}
The 26 development cases use two losses, dimensions 6 and 8 with budgets 2, class sizes 4 and 8, and seeds 3, 7 and 11; two additional cases use dimension 12, budget 3 and four observations per class. These cases use a shared deliberately poor tail-coordinate start.
Stage 1 changes the prediction score or gives a refreshed master candidate priority. Stage 2 adds data-ranked proposals or chooses a tangent on the same point's dual optimal face; the latter incurs an extra continuous solve. Stage 3 retains fractions and solves a fraction master at every step. Stage 4 keeps those fractions but refreshes only periodically. Changing the score alone did not reduce evaluations. The last two stages reduce evaluations through stronger stored lower bounds, while their integer masters cost more per call.

\subsection{Independent confirmation}
The 16 predeclared confirmation configurations use $(D,d)=(7,2)$ or $(10,3)$, six observations per class, seeds 19 and 23, radii $(0.12,0.20)$ or $(0.30,0.45)$, and half-hinge or logistic loss. They reuse 4 generated datasets across losses and radii. Generated coordinates are used directly, without the standardization fitted in the reference statistical study. Class zero is Gaussian; class one shifts its first two coordinates by 1.4 and 0.9. Nuisance scales span 0.3 to 3. Dimension and budget change the support space; unequal radii and the two losses check both asymmetric uncertainty and linear/conic solver costs. This is an optimization-effort study, not a new power study.
All methods use the same data-ranked start. The score numerator is the absolute class-mean difference; its denominator is the sum of both class standard deviations and $10^{-12}$. Standard deviations use \texttt{ddof=0}; ties are resolved by stable index order. No generating signal identity is used.
The allowance is 60 s per run, with one solver thread, no fractional root evaluations, absolute risk tolerance $\varepsilon=2\times10^{-5}$ and zero relative tolerance. Inner and master precision targets are $\varepsilon/4$. The normalized risk predictor has prior mean $1/2$, covariance $\frac14\exp[-\|z-z'\|_1/\max(1,d)]$ and ridge $\max\{10^{-8},(\varepsilon/(4B))^2\}$, where $B=1$ for half hinge and $B=2\log2$ for logistic. These parameters are fixed.
Each method is timed 3 times per configuration, rotating execution order. Times below sum the within-case medians; query counts are unchanged across those repetitions. The 16 configurations are paired settings on 4 datasets, so no independent-trial confidence interval is attached to these totals.
