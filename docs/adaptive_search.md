# 新版搜索：每个选中的组合都完整求解

本说明对应 0.5.0 的当前搜索 `full_inner_uncertainty_v3`。英文与中文理论笔记的第五节描述同一算法；附录 C 证明其正确性和完整评估次数界，附录 E 说明候选风险预测。0.4.0 与早期几何评分版本的结果保存在各自验证记录中，不能作为当前算法的实验结果。

## 1. 一次真正的评估是什么

选定二元向量 \(z\) 后，调用 `GateOracle.solve(z)` 完整优化该组合上的检验。记 \(V(z)\) 为这个内层问题的最优风险，\(B\) 为常数检验给出的初始风险上界，\(\varepsilon\) 为外层绝对精度。求解器返回可行检验、实际风险上界 \(R\)、对偶下界 \(\ell\) 和梯度 \(g\)。要求实际修复后满足

\[
\ell\le V(z)\le R,\qquad R-\ell\le\delta=\varepsilon/4.
\]

然后只保留该点评估得到的一条切线：

\[
L(x)=\ell+g^\top(x-z).
\]

下一组变量的内层问题仍会完整求解。数值模型可以热启动，但不会把旧检验或旧运输矩阵固定成新问题的解。精度重试属于同一组合的一次完整评估；完成后只增加一条切线。

## 2. 历史信息只决定先求解哪个组合

`EvaluationHistory` 保存已评估组合 \(z^s\)、各自的实际风险上界 \(R_s\) 和切线 \(L_s\)。已有切线给候选 \(x\) 提供全局有效的下界：

\[
a_t(x)=\max\{0,L_s(x):s\le t\},\qquad
U=\min\{B,R_s:s\le t\}.
\]

若 \(a_t(x)>U-\varepsilon/2\)，该候选已经缺少所要求的改善空间，不再完整评估。候选排序只在满足

\[
a_t(x)\le U-\varepsilon/2
\]

的组合之间进行。

怎样区分这些仍有希望的组合？用完成评估的 \((z^s,R_s)\) 训练一个简单的 Gaussian 预测器。两个组合差异越少，预测时越多地共享已知风险信息。其固定相似度为

\[
k(z,z')=\tfrac14\exp\!\left[-\frac{\|z-z'\|_1}{\max(1,d)}\right],
\]

其中 \(d\) 是变量预算，二元向量间的 \(\|z-z'\|_1\) 就是不同坐标的个数。风险先除以 \(B\)，先验均值取 \(1/2\)，数值稳定项固定为 \(\nu=\max\{10^{-8},(\delta/B)^2\}\)。预测器输出风险单位下的均值 \(m_t(x)\) 和标准差 \(\sigma_t(x)\)。初始没有观测时，两者均为 \(B/2\)。

在通过切线筛选的候选中，选择

\[
\arg\min_x\bigl[m_t(x)-\sigma_t(x)\bigr].
\]

预测风险低使候选值得尝试；预测尚不确定也使它值得完整求解。这个分数只决定求解顺序。均值与标准差都不更新 \(U\) 或全局下界，不生成检验，也不生成候选处的新切线。标准差描述预测模型的不确定性，不是对真实风险经过校准的置信界；预测均值也无需强制落在 \([0,B]\) 内。

候选池默认最多 8 个组合，来源是近期切线建议的坐标交换、坐标排序及少量多样性组合；新全局候选也占其中一个位置。预测只需要复用矩阵分解后的三角求解，不调用内层优化器，不重新拟合核参数。每次完整评估只向 Cholesky 因子追加一行；第 \(t\) 次更新和固定大小候选批次的预测各需 \(O(t^2)\) 算术操作，另有相似度向量的计算。附录 E 给出均值、标准差和追加公式。

## 3. 全局主问题负责认证

没有通过筛选的候选时，或达到设定的认证周期时，求解由全部保留切线构成的二元主问题。它给出全局下界 \(LB\) 和一个整数候选。

若 \(U-LB\le\varepsilon\)，当前真实检验已达到绝对目标精度。否则，在主问题候选误差不超过 \(\varepsilon/4\) 时，该候选必能通过改善筛选，因此可以继续完整求解。几个交换失败不会被当作算法收敛。相对容差只放宽停止条件为 \(U-LB\le\varepsilon+\varepsilon_{\rm rel}|U|\)；筛选和内层精度仍使用固定的绝对 \(\varepsilon\)。

代码用有效的主问题全局界更新 \(LB\)。未求到最优时，这个界来自 `mip_dual_bound`；只有已经证明主问题最优时，才可用其最优目标值代替。中途的主问题可行目标值不属于全局下界。未获得要求的主问题精度时，返回相应退出状态和当前有效界。

## 4. 哪些代码实现哪些公式

| 文件 | 关键入口 | 数学作用 |
|---|---|---|
| `oracle.py` | `GateOracle.solve` | 完整求解、修复上下界、计算该点梯度；保留数值模型用于热启动 |
| `history.py` | `EvaluationHistory.add` | 一次完成的二元评估只增加一条该点切线；达到精度要求的实际风险进入预测器 |
| `history.py` | `lower` | 计算切线下界 \(a_t\)，用于改善筛选 |
| `history.py` | `FixedKernelPredictor.append`、`predict` | 追加 Cholesky 因子，批量计算预测均值与标准差 |
| `history.py` | `proposal_pool` | 生成受限数量的组合，避免枚举全部交换 |
| `adaptive.py` | `evaluate` | 完整评估和实际精度检查；仅这里更新真实检验与 \(U\) |
| `adaptive.py` | 主循环与 `master` | 改善筛选、均值减标准差排序、全局下界和停止 |
| `solver.py` | `solve` | 新算法默认入口，以及旧主问题搜索的独立入口 |

`scalar_upper` 和 `bounds` 保留作距离界的独立核查工具，当前搜索不调用它们排序。新版默认路径没有分数点内层求解、历史检验转移或候选处切线生成。`root_rounds`、替代 gate 和完整分式 master 属于保留的旧搜索路径，不是第五节的算法。完整分式 master 的推导单独保存在 `docs/ratio_cut_derivation.md`，与当前预测附录 E 无关。

## 5. 保证与验证的范围

每次选择的组合都必须通过已有切线的改善筛选，完整求解后满足实际误差要求。其新切线会排除同一个组合再次进入完整评估。附录 C 进一步证明，两个评估组合之间的加权距离至少为 \((\varepsilon/2-\delta)/B\)，并用坐标尾权重给出可计算的次数界。这些保证由切线、精度要求和全局主问题得出，不要求预测器正确描述真实风险。

定理统计达到精度要求的二元组合评估次数，不统计求解器内部迭代、精度重试或实际运行时间。精度或时间预算耗尽时，只返回当前有效上下界，不宣称已经收敛。

诊断标签是 `full_inner_uncertainty_v3` 与 `fixed_hamming_gp_v1`。记录包含实际评估数、因子追加次数、预测耗时，以及每次候选池的均值和标准差范围、所选候选是否不同于仅按切线下界选择的候选。它们可以检查不确定性是否实际影响排序，不能证明预测概率已经校准。

新验证独立保存于 `reports/verification/20261010/`，以记录中的搜索版本识别算法。原 1,640 条正式实验记录、冻结配置和旧实验报告保持其原算法版本。
